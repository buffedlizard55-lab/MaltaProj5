Method & sources

How each row was produced, and the rules that governed it.

Rules applied

  1. Geography. Only events inside the City and County of San Francisco. Events at Levi's Stadium, the Cow Palace and other out-of-city venues are excluded and listed on Flagged for Review.
  2. Official sources only. Every row cites the organizer's site, a City of San Francisco page (sf.gov, sfrecpark.org, sfmta.com, sfpl.org, sfport.com) or the venue's own page. Aggregator calendars (Funcheap, SF Station, Timeout, hotel and travel blogs) were used only to discover candidate events, never as a row's source.
  3. No inference. If a value could not be read off an official page it was left blank and the row marked unverified. Dates were never extrapolated from a previous year's pattern, even where the pattern is obvious.
  4. Conflicts are published, not resolved silently. Where two official sources disagree, the row is marked flagged and the disagreement is written out with both sources named.
  5. Reproducibility. The register is generated from data/events.json by tools/build_site.py; tools/validate.py enforces the schema and tools/linkcheck.py checks every internal link in the built site.

Schema

Each event row carries:

idnamecategoryrecurrencecadencenext_datedate_statusscheduletimevenueneighborhoodorganizercostsource_namesource_urlverified_onstatusnotes

date_status is confirmed when the date cell holds a date read from an official page, and unverified when the field is empty because no official page publishes one. status is flagged only for genuine irregularities.
