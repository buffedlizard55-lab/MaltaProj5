# MaltaProj5 — San Francisco Events Register

A verified register of events held **inside the City and County of San Francisco**, organised into
events that recur (weekly, monthly, annually) and dated special events — with the analysis, the
source ledger, and the irregularities found while verifying them.

**86 entries · 75 official source records · every row links to the official page it was checked
against on 18 October 2026.**

This register is the merged output of two independent research passes run in parallel
(sessions `3a19e72d` and `5a85baf2`); see `COORDINATION.md` for the board and the merge record.

## The site

The published site is built at the repository root and deployed by
`.github/workflows/pages.yml`.

| Page | Contents |
|---|---|
| `index.html` | Overview: counts, entry points, all entries |
| `weekly.html` / `monthly.html` / `annual.html` | Recurring events, by pattern |
| `special.html` | Dated special events and editions |
| `markets.html` / `museums.html` / `culture.html` / `community.html` | By category |
| `review.html` | **Flagged for Review** — unverified values, source conflicts, coverage gaps, publication blockers |
| `sources.html` | Sources & method: verification rules, the official-source ledger with excerpts, row-by-row evidence |

Every table row carries an Evidence / review cell. **A blank cell means unverified, not "free" and
not "not applicable."** No value is inferred: where an official page does not state something, the
field is empty and the row carries a review note.

## Working on this repository

Read `COORDINATION.md` first — it is the shared task board. Claim a task with your session ID and
file scope, commit and push the claim before starting, and keep scopes non-overlapping.

```bash
python3 data/build_data.py    # regenerate session 5a85baf2's authored rows
python3 tools/integrate.py    # merge both authored registers into data/events.json
python3 scripts/build.py      # build the site
python3 scripts/validate.py   # data + local link/fragment checks
python3 tools/remotecheck.py  # fetch every official source URL (needs network; runs in CI)
```

`data/events.json`, `data/events.csv` and the `*.html` pages are generated and committed, because
GitHub Pages serves them from `main`. CI fails if any of them is stale — commit data and site
together.

## Verification rules

1. **Geography.** Only events inside the City and County of San Francisco. Events at Levi's
   Stadium, the Cow Palace and other out-of-city venues are excluded and recorded on
   `review.html`.
2. **Official sources only.** Organizer sites, venues, museums and City pages (`sf.gov`,
   `sfrecpark.org`, `sfmta.com`, `sfpl.org`, `sfport.com`) supply admitted facts. Third-party
   calendars were used for discovery only, never as row evidence.
3. **No inference.** Dates are preserved as published. Next occurrences are never generated from a
   previous year's pattern, and a recurring pattern is never presented as a confirmed future
   instance.
4. **Conflicts are published.** Where two official sources disagree, the disputed value is blanked
   and both sources are named on `review.html`.
5. **Coverage is not claimed to be exhaustive.** There is no citywide denominator; gaps are stated
   on `review.html` rather than hidden.
